# group-3

Full-stack course project (Express static server + frontend).

Project name: **group-3**. The GitHub repo should match (rename when ready).

- After renaming the repo to `group-3` on GitHub: **Settings → General → Repository name** → `group-3`.
- Then point your local `origin` at the new URL:

  `git remote set-url origin git@github.com:Senati-V-2026-1/group-3.git`

Until then, the remote may still be `Senati-V-2026-1/group-4` (GitHub redirects after rename, but updating `origin` avoids confusion).

## Run locally

```bash
npm ci
npm start
```

Open http://localhost:3000
